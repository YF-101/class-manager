# 班主任班级成绩管理系统

基于 Flask、Jinja2、SQLite 的多老师成绩管理网站。

支持注册登录、独立老师数据、多班级管理、学生与考试管理、学生专属账号与本人成绩查询、自定义科目/满分/及格线、成绩录入修改与单条删除、缺考登记、完整成绩总分排名（同分并列）、各科统计、得分率趋势图、动态科目 Excel 导出、不及格标红和打印。

## 本地运行

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

打开 http://127.0.0.1:8080 。首次创建数据库时，随机管理员初始密码保存在 `.instance/admin-initial-password`，登录后必须更改。不再提供公开的默认密码。旧数据库升级保留原密码；仍使用旧默认密码的管理员会被要求先改密。

数据默认保存在项目 `class.db`。可用 `CLASS_MANAGER_DB` 指定路径；未配置环境密钥时，本地随机密钥保存在 `.instance/secret-key`。`.instance`、数据库、备份都不能提交或公开。

## 测试、升级与备份

```bash
python -m unittest discover -s tests -v
python migrate.py
python backup.py
```

回归测试只用临时数据库和模拟邮件，不接触真实数据。首次升级会先备份现有数据库；迁移可重复运行。

**生产部署、密钥、数据库恢复和每日备份任务设置见 [DEPLOYMENT.md](DEPLOYMENT.md)。** 在 PythonAnywhere 使用 Web 面板配置的虚拟环境安装依赖，再 Reload。

## 统计规则

- 所有科目都有有效正常成绩的学生，按总分排名；同分并列，后续名次跳位。
- 未录入、明确缺考与异常记录分开显示，暂不参加完整成绩排名。0分是正常成绩，不等于缺考。
- 平均分、及格率、优秀率仅使用有效正常成绩为分母；优秀线为满分85%。
- 不同考试的趋势图使用得分率，便于比较不同满分的考试；缺考和未录入不连线。
- 停用老师立即阻止登录并使原会话失效，保留其学生和考试数据，可恢复账号。
- 管理员可以管理其他老师的数据，但不能把一个老师的学生录入另一个老师的考试。
- 老师在学生档案页创建学生账号；学生首次登录必须修改密码，之后只能查看自己的成绩。

## 主要文件

- `app.py`：路由、会话、权限、邮件、成绩统计和导出。
- `database.py`：事务、数据库迁移、备份和数值校验。
- `templates/`：界面与打印样式。
- `migrate.py` / `backup.py`：升级与一致性备份命令。
- `tests/test_regressions.py`：权限、安全、业务与旧库迁移回归测试。

已支持家长独立邮箱账号与学生绑定，家长只能查看自己孩子的成绩。已支持 Excel 批量导入学生和整班表格录分。

## 一位家长关联多个孩子

老师在学生档案页输入家长邮箱，新账号需设置初始密码；已有家长邮箱可直接关联其他孩子，密码留空，原密码保持不变。家长关联多个孩子后，首页显示孩子列表，成绩页也提供切换入口；不同老师只管理各自学生的关联，看不到其他孩子的绑定信息。

解除关联立即撤销该孩子的查看权限，保留家长账号；未关联孩子时显示联系老师的提示。删除学生时，保留仍关联其他孩子的家长账号及密码找回记录；仅删除没有其他孩子的关联家长账号。

数据库版本6增加 `parent_students` 关联表，原有家长绑定自动迁移。版本5升级只新增关联表和版本号，保留业务行、账号、密码哈希、会话版本和找回密码记录；升级前自动备份。`users.student_id` 对学生账号仍是唯一绑定，对家长仅保留兼容用的首个孩子，家长权限以关联表为准。版本6数据库不能直接退回旧代码。

## Excel 批量导入学生

在学生名单页选择班级，点击“Excel 批量导入学生”。下载空白模板，第一行保留“姓名”和可选“学号”，从第二行填写；学号建议使用文本格式。支持 .xlsx，第一个工作表，每批最多500人，上传内容限1MB，解压后内容限8MB。

上传只预览，不写入。显示原始行号、同班重复姓名/学号、文件内重复及格式错误；任何一行有错误时整批不能导入。确认前会再次校验目标班级权限与最新名单，所有记录在同一事务中保存，防止重复提交和预览后名单变化造成部分导入。预览30分钟有效，绑定当前账号和会话版本。

## 整班表格录分

考试管理中点击“整班录分”，按学生行、科目列输入分数或“缺考”。空白为未录入，清空已有值会删除该条成绩，0分仍为正常成绩。可从 Excel 粘贴分数区域，超出本页范围时整次粘贴取消；离开未保存页面会提示。每页最多30人（科目特别多时自动减少），只保存当前页的改动。

保存前统一校验整页，任一错误均不写入，保留输入并标出单元格。录分页面1小时有效，保存时检查账号、考试、名单、科目配置与当前页原有成绩，发生变化时返回409并阻止覆盖；需复制输入后重新加载。其他页的成绩更新不会使当前页失效。历史已录分的转班学生可继续修改，未参加该考试的其他班级学生不能录入。
